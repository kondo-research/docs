# 研究所について

近藤研究所は、インターネットと AI の時代にふさわしい新しい形の研究所を目指して設立された、東京の私設研究所です。

## 考えかた

インターネットと AI によって、世界は大きな変化の時期に入っています。なかでも大きく変わりつつあるのは、研究や知的作業のあり方そのものです。インターネットは世界の情報空間をつなぎ、いま AI はそこで行われる知的作業を変えつつあります。

当研究所は、AI 時代における人間の役割を問い直しながら、人と人との知的な議論を中心に据えたまま、独立した研究者が自らの問いを自由に立てられる場をどう作るかをテーマとしています。

## 研究領域

| 領域 | 内容 |
|---|---|
| 存在からの物理学 | 「存在する」とは何かを定式化し、そこから標準模型のパラメータを導く理論 |
| 量子計算 | 量子暗号解析、耐量子暗号、量子誤り訂正 |
| 分散コンピューティング | Web とインターネットを基盤とする分散的な情報アクセス。ブラウザとブロックチェーン |

詳しくは [研究](research.md) を参照してください。

## 所長

**近藤秀和** — 東京を拠点とする研究者・起業家です。分散コンピューティングの研究から出発し、量子計算を経て理論物理・数学・暗号・AI へと領域を広げ、これらを統合する理論的枠組みとして存在からの物理学を提唱しました。研究と並行して複数の技術企業を創業し、研究成果を製品として世に出しています。
