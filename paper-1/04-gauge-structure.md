# 4. 射影平面からのゲージ構造

前章では2つの数が導かれた——シュレーディンガー方程式が持つ束縛状態の数 N = 3（§3.3）と、その実現の整合性が定める空間の次元 d = 3（§3.4）である。2つは独立に導出された——にもかかわらず、同じ値 N = d = 3 を取る。本章では N = 3 から、3元体 F₃ 上の3次元空間 F₃³ を構成する——「3」が単なる個数ではなく体になる理由、および階数 3 が3つの束縛状態から来ること（d = 3 は入力ではない）は §4.1 で示す。本章では、そこから生じる幾何学的構造が、標準模型のゲージ構造と同じ数学的構成を持つことを示す。

## 4.1. ゲージ構造の起源

N = 3 からどのようなゲージ構造が生じるか。鍵は縮退の有無にある。本構成で内部方向の連続回転対称性を担うのは、縮退——同じ内部エネルギーを持つ方向——である。

標準模型の側では、クォークのカラー（赤・緑・青）がその典型であり、どの色も同じエネルギーを持つため連続的な回転対称性 SU(3) が立つ。一方、導出された側の世代——V = −H の3つの束縛状態——は全て異なるエネルギーを持ち（E₀ ≠ E₁ ≠ E₂、Sturm-Liouville の定理）、優先固有基底が存在する。この基底を保存する対称性は離散的であり、連続なゲージ群を支えない[^gencas]。従ってゲージ方向は世代の入れ替えからは生じない——空間 F₃³ の幾何から来なければならない。以下でその幾何を構成する。

[^gencas]: §7.1 の質量式の接触指数 b = 8/3 は有限入射幾何から導かれる量であり、これと両立する（SU(3) Casimir との数値一致は N = 3 限定の整合性検査、§7.1）。

$$N = 3 \xrightarrow{\text{世代の巡回}} C_3 \xrightarrow{\;\mathrm{End}\;} \mathbb{F}_3 \xrightarrow{\text{自由加群}} \mathbb{F}_3^3 \xrightarrow{\text{射影化}} \mathrm{PG}(2,\mathbb{F}_3)\;(13\text{点}) \xrightarrow{\;\text{旗}\;} 9{+}3{+}1$$


N = 3 から、体 F₃ = {0, 1, 2} 上の3次元空間 F₃³ が定まる。体構造の由来は、世代の入れ替えにある。3つの束縛状態を巡回的に繰り上げる操作（1→2→3→1 とその反復）の全体は S₃ の唯一の非自明な真の正規部分群 C₃ をなし、どの状態からどの状態へもちょうど一通りの繰り上げで移れる。繰り上げの合成を保つ写像は 0 倍・1 倍・2 倍の3通りしかなく（自己準同型環）、これが足し算と掛け算を備えた体 F₃ = ℤ/3ℤ をなす——ここで 3 は個数ではなく体になる。

$$C_3 = \{e,\ c,\ c^2\},\qquad \mathrm{End}(C_3) = \{\,c \mapsto c^k : k = 0, 1, 2\,\} \cong \mathbb{Z}/3\mathbb{Z} = \mathbb{F}_3$$

3つの束縛状態それぞれに一つの基底方向を割り当て、F₃ 係数の線形結合だけを許して自由に完備化したものが F₃³ である（三状態上の自由 F₃-加群、|F₃³| = 3³ = 27 元；この構成の定理化は Paper II が与える）。空間次元 d = 3 は同じ数字を持つ独立な定理であって F₃³ の階数の入力ではなく、N = d = 3 は整合性の一致として残る。以下の射影空間の構成には体（群ではなく）が必要であり、N = 3 が素数であるため F₃ = ℤ/3ℤ が N 元素の唯一の体として一意に定まる——実際、3元体の加法群は位数 3 なので 1 が生成する ℤ/3ℤ に一致し、乗法は分配則により加法から決まるから、演算表ごと一意である。

F₃³ の中から原点を除いた2次元の断面を見ると、F₃² = {0,1,2} × {0,1,2}——3×3 のグリッド——が現れる。この9点が以降の構成の出発点となる。

3×3 グリッド上で直線を引くと、同じ傾きの直線は平行になり交わらない。射影幾何ではこれらが「無限遠の1点」で合流する——透視図法で平行な線路が地平線上の1点に収束するのと同じ原理である。F₃² 上の直線の傾きは |F₃| + 1 = 4 種（0, 1, 2, ∞——水平・右斜め・左斜め・垂直）であり、各傾きに対応する無限遠点が1つずつ生じる。この4点を結んだものが無限遠ライン L——地平線に相当する。

元の9点に4つの無限遠点を加えると 9 + 4 = 13 点。これが射影平面 PG(2, F₃) である——F₃³ の原点を通る1次元部分空間を「点」、2次元部分空間を「ライン」と定義した空間で、13点・13ライン・各ライン上4点・各点を通るライン4本という対称的構造を持つ（図2）。

$$|\mathrm{PG}(2,\mathbb{F}_3)| = \frac{3^3 - 1}{3 - 1} = 13$$

![射影平面 PG(2, F₃) の構造](img/fig_pg23_v2.png)

*図 2. 射影平面 PG(2, F₃) の構造。3×3 グリッド（9点、黒丸）の平行線が無限遠ライン L 上の方向（白丸）で合流する。P₀（黒菱形）を選ぶことで 9+3+1 = 13 の分割が生じ、これが SU(3)×SU(2)×U(1) のセクター構造に対応する。*

PG(2, F₃) の完全な対称性 PGL(3, F₃) のもとでは、13点は全て等価であり分割は生じない。ここで無限遠ライン L 上の4点のうち1つを基準点 P₀ として固定する——この組 (P₀, L) を旗（フラグ）と呼ぶ。旗の固定は構成内の基準選択であり、PGL(3, F₃) は旗に推移的に作用するため、どの旗を選んでも同型な分割を与える。固定により13点は、旗を保つ変換のもとで互いに混合しない3つの軌道に分かれる：L の外にある9点（3×3 グリッド）、L 上で P₀ 以外の3点、P₀ の1点。P₀ だけでは 1+12 の2グループにしかならず、旗を選んで初めて 9+3+1 の3グループが生じる。これが3つの力を区別する最小の構造である：

$$N^2_{(9\;\mathrm{colour})} + N_{(3\;\mathrm{weak})} + 1_{(1\;\mathrm{hyp})} = N^2 + N + 1.$$

N = d を満たすのは N = 3 のみである（N = 2, 4, 5 はいずれも d = 3 ≠ N）——これは整合性の一致であって入力ではない。分割 9+3+1 の全ての数は N のみで決まる：N² = 9、N + 1 = 4（うち参照点を除き N = 3）、参照点 1。合計 N² + N + 1 = 13。52個の旗（点-ライン対）がラプラシアンの基底を与える（§5.3）。

## 4.2. 13点から標準模型ゲージ群へ

この 9+3+1 の分割は、標準模型のゲージ群 SU(3)×SU(2)×U(1)_Y のセクター構造と同じ型を持つ。ここで、この分割を標準模型のゲージセクターだと仮定する。この段階では仮の同定であるが、§5 でこの同定から結合定数が、§8 で混合角が導かれ、実測値と一致することから、同定は確からしいと言える。

**9点 → SU(3)。** L 外の9点はアフィン平面 AG(2, F₃) を構成する。この9点は (a,b) ∈ F₃² でラベルされ、3次元内部表現における有限 Weyl 演算子 W_{a,b} = XᵃZᵇ を自然に添字づける。単位元 W_{0,0} は中心成分であり、残る8つの非自明な Weyl 成分が トレースレスセクターを構成する。この 階数 2・次元 8 のコンパクト単純リー完成は Killing-Cartan 分類により su(3) に一意に定まる。9番目の中心成分は大域バリオン数 U(1)_B に対応する（ゲージ化されない大域荷であり、アノマリーフリーな厳密結合は B−L である、§8.3）。

**3点 → SU(2)。** L 上で P₀ 以外の3点は、基準点に対する3つの非自明な弱方向を与える。この3方向の最小非可換コンパクトリー完成は3生成子の su(2) であり、その二重項表現が弱 SU(2) 作用を与える。

**1点 → U(1)_Y。** 基準点 P₀ はアーベル中心モジュール位相を与え、物理的にはハイパーチャージ U(1)_Y に対応する。

**直積構造の保証。** アフィン平面の平行移動は無限遠ライン L を固定する——グリッドをずらしても「方向」は変わらない。カラーセクター（9点）の変換は電弱セクター（3+1点）と混合しない。これは PG(2, F₃) の入射構造から従う幾何学的性質であり、三つのセクターが互いに混合しないという直積型の構造を与える——標準模型のゲージ群と同じ形である。群の大域形（標準模型では Z₆ 商を含む [38]）は幾何だけでは決まらず、粒子担体への忠実作用から定まる^II^。

$$n^2{=}n \xrightarrow{V=-H} N{=}3 \xrightarrow{\text{自由加群}} \mathbb{F}_3^3 \xrightarrow{\text{方向を数える}} 13\text{点} \xrightarrow{\text{旗}} 9{+}3{+}1 \xrightarrow{\text{Killing-Cartan}} \mathfrak{su}(3)\oplus\mathfrak{su}(2)\oplus\mathfrak{u}(1).$$

この数学的導出結果は、実験で確立されたゲージ構造 SU(3)×SU(2)×U(1) と一致する。

ライン上の4点は SU(2) 二重項の4つの実自由度——SU(2)×U(1) → U(1)_em の破れに必要な3つの Goldstone ボソンと物理的ヒッグス——に対応する。V = −H は φ = 0（σ = 1/2）で最小値 −ln 2 を取り、φ → ±∞ でゼロに戻る安定な井戸である（V''(0) = 1/4 > 0）。真空は場の消失点（σ ∈ {0,1}）ではなく内部点 σ = 1/2 に位置する——標準模型で負の二次項（μ² > 0）が果たす役割、すなわち真空を対称点から有限の場の値へ移すことを、ここでは井戸の形状が担う。


## 4.3. フェルミオンの多様性の起源

§4.2 までで、PG(2, F₃) の13方向が標準模型のゲージ群と同じ形の構造を持つことを確立した。しかし13方向はフェルミオンそのものには対応しない。13方向はゲージ対称性——力の構造——を定め、フェルミオン構造はこのゲージ群の**表現**として現れる。ここでは、唯一の存在変数 n がなぜ多様な物質粒子構造として発現するかを示す。

n は唯一である。ゲージ構造が出現する前、n は量子数を持たない——世代ラベルもカラーもアイソスピンもない裸の自由度である。区別する性質がなければ複数の n は同一であり（Leibniz の不可弁別者同一の原理）、n は唯一に留まる。PG(2, F₃) のゲージ構造がこれを変える：ゲージ群の表現が内部空間に多様な「居場所」——配位——を生み、各配位に占有数 n_i ∈ {0,1} が対応する。配位分解は：

$$\sum_{i} \hat{n}_i = \hat{n}, \qquad \hat{n}_i^2 = \hat{n}_i, \qquad \hat{n}_i \hat{n}_j = \delta_{ij}\,\hat{n}_i$$

三つの式は一粒子の層の主張である：第一式は存在が配位に分解されること、第二式は二値性（n² = n）が各配位に継承されること、第三式は唯一の存在単位がちょうど一つの配位を占めることを述べる。まとめれば、n̂ᵢ は互いに直交し n̂ に足し上がる射影——一粒子状態空間の直交分解——である。

Pauli 排他律そのもの——同一モードの二重占有の禁止と交換反対称性——は、各配位をモードとする多体実現（CAR＝正準反交換関係の構成）^II^が担う。多体実現では異なる配位は同時に占有されうるが、各モードの占有は {0,1} に制限される——これが Pauli 排他律の占有数表現である [11]。なお n_i = 0 は非存在（A3 が禁じた σ = 0）ではない——存在が別の配位を占めているだけである。

各配位 i は2つのラベル——世代 k（V = −H のどの束縛状態か）とゲージ表現 α（PG(2, F₃) のどのセクターに属するか）——で特徴づけられる：

$$n_i = n_{k,\alpha},\qquad k = 1, 2, 3$$

ゲージ群 SU(3)×SU(2)×U(1) の表現は1世代あたり16状態を与え、3世代で48配位となる（下表）。

左右非対称性（SU(2) が左巻き場のみに作用すること）は、この粒子種指定の一部であり、本論文では導出しない。Paper II では、明示した列挙条件の下で混合配置が排除され、左右の割り当ては大域的な向きの規約を除いて一意に定まる。下表のハイパーチャージは、9+3+1 セクター構造、湯川閉包、ν_R の包含、および局所可換ゲージ因子を1つとする指定（B−L はゲージ化されない大域荷、§4.2）と両立する唯一のアノマリーフリーな割当であり、その演算子レベルの導出も Paper II が与える：

| 表現 | 内容 | 状態数 |
|---|---|---|
| (3, 2, 1/6) | 左巻きクォーク Q_L | 6 |
| (3, 1, 2/3) | 右巻き上型 u_R | 3 |
| (3, 1, −1/3) | 右巻き下型 d_R | 3 |
| (1, 2, −1/2) | 左巻きレプトン L_L | 2 |
| (1, 1, −1) | 右巻き荷電レプトン e_R | 1 |
| (1, 1, 0) | 右巻きニュートリノ ν_R | 1 |

合計 16 × 3 世代 = 48 配位（Weyl 成分で数え、反粒子は含めず、ν_R を含む）。ν_R の包含は湯川閉包および B−L 保護された Dirac 型ニュートリノ構造（§8.3）に必要である。ゲージ群 SU(3)×SU(2)×U(1) の生成子は 8+3+1 = 12 個のゲージボソン（グルーオン8、W⁺W⁻Z 3、光子1）に対応する。これに §4.2 のヒッグス1つを加え、48フェルミオン・12ゲージボソン・1ヒッグスが標準模型の全粒子内容を構成する。

こうして、唯一の存在（n）から多様な物質（n_i）が生まれる——物質の多様性はゲージ構造の帰結である。

この構成の内部整合性は、固有関数の参加比

$$D_{PR} = \frac{(\int \rho\, d\varphi)^2}{\int \rho^2\, d\varphi} = 13.06 \approx |\mathrm{PG}| = 13,\qquad \rho = \sum_n \psi_n^2$$

（ρ は3束縛状態の合計密度。付属の検証コードで再現可能）と、52×52 旗ラプラシアンのスペクトル分解により独立に確認される[^flagspec]。導出のいかなるステップにも自由パラメータは含まれない。この構成の正当性は、§5–§10 で導かれる独立な物理量が全て 0.0006%–2.6% の精度で実測値と一致することにより裏付けられる。

[^flagspec]: Paper II の有限核定理とスペクトルゲージ分解の系。
