# 7. フェルミオン質量

§4–6 でゲージ構造、結合定数、ヒッグス質量に対応する構造を確立した。§3 で置いた世代の仮同定に基づき、本章では束縛状態の局在度から質量比の数式を導き、世代間の混合は次章で導く。導かれた質量比は、荷電レプトン・クォーク・ニュートリノの実測値と高い精度で一致する——この一致により、§3 の仮の同定は裏付けられる。

## 7.1. 質量公式

V = −H の3つの束縛状態は局在度が異なる。最も深い ψ₀ は井戸の底に局在しゲージ場と最も強く結合するため、最も重い τ に対応する：

| 束縛状態 | エネルギー | 局在度 | 対応粒子 | 質量 (MeV) |
|---|---|---|---|---|
| ψ₀ | E₀ = −0.485 | 高（井戸の底） | τ | 1777 |
| ψ₁ | E₁ = −0.159 | 中 | μ | 106 |
| ψ₂ | E₂ = −0.010 | 低（井戸の縁） | e | 0.511 |

質量比は波動関数の局在度で決まり、独立パラメータではない。標準模型が3つの Yukawa 結合として手で入力する階層を、ここでは1つの井戸の3つのモードの局在の差が与える。鍵となる量は R = ln(m_τ/m_e)/ln(m_μ/m_e) であり、3体の質量階層を1つの数に圧縮する。

$$V = -H \xrightarrow{\text{§3}} \psi_n \xrightarrow{\text{IPR}} \text{局在度} \xrightarrow{b} m_n \xrightarrow{} R = 1.5293$$

各固有状態は束縛エネルギー |E_n| と局在度を持つ。局在度は逆参加比 IPR_n = ∫|ψ_n|⁴dφ で測られる。ゲージ場との結合強度は相互作用点における波動関数の振幅に比例するから、内部空間で局在した状態ほど大きな質量を獲得する：m_n ∝ IPR_n^b。

指数 b は自由パラメータではない。0次元ではループ積分が存在せず、異常次元を動的に生成するランニングが存在しない。有限群の Peter-Weyl 定理により、群上の熱核は有限和 K(t) = Σ_ρ dim(ρ) χ_ρ(g) e^{−λ_ρ t} となり、べき乗則を含まない——指数は構造が定める量である。そこで b は、有限入射幾何 PG(2, F₃) の規格化から導かれる接触指数である：一本の脚の規格化された指標 w_leg = (N+1)/N を用いて b = 2w_leg = 8/3[^casimir]。この対応規則の一意性は定理である^II^[^massuniq]。

これに V = −H の非調和性からの小さな補正が加わる。各モードが井戸を異なる仕方でサンプルすることをビリアル比 |⟨V⟩_n|/T_n（ポテンシャルと運動エネルギーの比）が測り、その指数はモードあたりの限界性 ε/N = 0.219/3 = 0.073 と読む（ε は §3.2）。この読みは、総欠損 ε を三つの世代終端が担い（Tr D = ε）、世代終端の重みをその三終端支持上の正規化評価 (1/3)Tr D = ε/3 として読むものであり、挿入の分布によらない。値そのものは下の Koide 逆算と 0.07% で一致する。

完全な質量公式は：

$$m_n \propto |E_n| \times \mathrm{IPR}_n^{\,b} \times (|\langle V \rangle_n| / T_n)^{\varepsilon/N}$$

3つの因子は異なる起源を持つ：

| 因子 | 物理的意味 | 決定要因 |
|---|---|---|
| \|E_n\| | エネルギースケール | 束縛エネルギー |
| IPR^{b} | 局在度 → 結合強度 | 有限入射幾何（接触指数） |
| (|⟨V⟩|/T)^{ε/N} | 非調和補正 | スペクトル的限界性 |

全指数が V = −H から決まる。結果：

$$R = \frac{\ln(m_\tau/m_e)}{\ln(m_\mu/m_e)} = 1.5293 \quad (\text{実測: } 1.5294,\; 0.006\%)$$

（全スペクトル量は |φ|_max = 100, Δφ = 1.25×10⁻⁴ (N_grid = 1600001) で計算し、グリッド解像度の倍増および箱サイズの拡大で安定であることを検証済み。）

Koide [23] の関係 Q ≈ 3/2（本論文の規約 Q = (Σ√m)²/Σm は標準的な規約 2/3 の逆数）は、b を決める入力ではなく検算——出力側の検証——である。質量公式を Koide 型に径数化すると対 (b, c) が現れ、c はビリアル補正の指数に当たる。各 b に対して Q = 3/2 を強制するのに必要な c を逆算すると、b = 2w_leg = 8/3 のときにのみ、逆算値 0.0730 がスペクトル値 ε/N = 0.073 と一致する（0.07%）：

| b | c (Q=3/2) | 偏差 |
|---|---|---|
| 2.0 | 0.437 | 500% |
| 2.5 | 0.163 | 120% |
| **8/3 = 2w_leg** | **0.0730** | **0.07%** |
| 2.78 | 0.012 | 84% |
| 3.0 | -0.107 | 246% |

| | 予測 | 実測値 | 精度 |
|---|---|---|---|
| m_τ/m_e | 3481 | 3477 | 0.1% |
| m_μ/m_e | 207.0 | 206.8 | 0.1% |
| R | 1.5293 | 1.5294 | 0.006% |
| Q (Koide) | 1.499985 | 1.500005(11) | 2σ（PDG 質量より算出） |

R = 1.5293 の 0.006% 一致は、束縛状態とレプトン世代の同定を定量的に支持する。この量の実測精度は 6 × 10⁻⁶ と高いため、0.006% の差は実測不確かさに対して約 10σ にあたる。差は本節の表示次数によるものであり、次の次数を含めた評価は R = 1.529365（0.0008%、−1.3σ）を、帰還項まで含めた評価は R = 1.529371（−0.7σ）を与える^II^。Koide 関係が輻射補正の下で安定であることは Sumino [43] が論じている。

[^massuniq]: 質量応答の関数形と接触指数 b = 2w_leg = 8/3 は Paper II が一意性定理として与える。後者は、有限側の固有値を接触座標の冪へ渡す対応を固定した下での定理である。

[^casimir]: これはレプトンの物理的カラー荷ではない。b は入射幾何の接触指数であり、SU(3) 基本表現 Casimir との数値一致 2C_F = 8/3 は N = 3 に限る——(N²−1)/2N = (N+1)/N は N = 3 のときのみ成り立つ。この一致は N = 3 での整合性検査である。Paper II [20] 参照。

## 7.2. クォーク質量

§7.1 の質量公式はレプトンで R = 1.5293 を再現した。同じ公式がクォークにも適用できるか。公式そのものは変わらない——変わるのは井戸の深さだけである。

レプトンはカラー一重項（色を持たない）であり、ポテンシャルは V = −H の1本分である。クォークは3色を持つ。カラー三重項の井戸は、三つの色寄与——同一の Bernoulli 自由度の同型な複製——を共通の存在座標 φ 上へ引き戻した独立寄与として積合成して得られる：Z₃ = Z₁³、対数の加法性から log Z₃ = 3 log Z₁、Legendre 双対の加法性から V = −3H^II^。弱アイソスピンが深くしないのは、二重項が単一の複製の内部の向き付け構造——どちらの成分を I₃ = +1/2 と呼ぶかを定めるもの（下記の g_c 補正）——であって、複製を追加しないからである。井戸が3倍深くなるため、束縛状態の数も増える——V = −3H は5個の束縛状態を支える（n_WKB = 4.82）。以下の表では井戸の深さ倍率（V = −κH の κ）を κ と書く：

| セクター | 作用素 | κ | 束縛状態 | 使用モード |
|---|---|---|---|---|
| レプトン | −H | 1 | 3 | (0,1,2) = τ,μ,e |
| アップ型 | −3H | 3 | 5 | (1,2,3) = t,c,u |
| ダウン型 | −3H（運動項に補正） | 3 | 4 | (0,1,2) = b,s,d |

**アップ型。** モード 0 は深く閉じ込められ I₃ = −1/2 セクターに属する。アップ型クォーク（I₃ = +1/2）はモード (1,2,3) を使い、同じ質量公式から R_up = 1.777（実測: 1.7697(25)、+0.41%＝+2.9σ）。色の帰還項まで含めた評価は R_up = 1.767（−0.17%、−1.2σ）を与え、同じ評価で軽クォーク質量比は m_u/m_d = 0.477（実測 0.460(16)）となる^II^。

**ダウン型。** アップ型とダウン型は同じ SU(2) 二重項に属し、同じ V = −3H を感じるが、弱アイソスピンの符号が異なる（I₃ = +1/2 vs −1/2）。この符号が質量公式に補正を与える。

SU(2) 二重項 (u, d) の全ゲージ荷の和 2C_F + 1/N_c = N_c は厳密な代数的恒等式である。この補正の物理的機構は PG(2, F₃) の幾何に由来する。ライン L 上の N+1 = 4 点のうち、基準点 P₀ が二重項の向き付け（どちらを I₃ = +1/2 と呼ぶか）を定める基準であり、残る3点が SU(2) ゲージ変換を生成する。I₃ の符号反転はこの向き付けの反転に対応し、内部空間上での SU(2) 作用の向きを反転させる。この反転が、全荷 N_c を§2.2 の Bernoulli Fisher 計量 g_F(φ) = σ(1−σ) = Var(n)（その一意性が Čencov の定理 [13]）に負符号で結合させる。有効質量は：

$$m_\mathrm{eff}(φ) = 1 − N_c σ(1−σ)$$

これはダウンセクターの質量式の静的 Fisher 極限形である。実際に解く演算子は位置依存質量の対称形 −½ ∂_φ (1/m_eff) ∂_φ − 3H である（付属の検証コードの離散化と同一）。

補正係数 g_c = −N_c = −3（§3.1 の規格化 g とは別の量）は SU(2) 二重項の代数的構造から定まる。補正後の演算子は負固有値を4個持ち（−1.5709, −0.5455, −0.1952, −0.00733；箱サイズ L_box = 40/80/120 で安定）、そのうち3モード (0,1,2) が物理窓 b, s, d に対応する——物理窓は型排他と順序保存から一意に定まる^II^（窓はセクターごとに異なる：レプトンは3モード全部、アップ型は (1,2,3)、ダウン型は (0,1,2)）。モード (0,1,2) で R_down = 2.273（実測: 2.276, 0.1%）。

3つの荷電フェルミオンセクターの質量比が全て再現される：

| セクター | κ | g_c | R（予測）| R（実測値）| 精度 |
|---|---|---|---|---|---|
| レプトン | 1 | 0 | 1.529 | 1.529 | 0.006% |
| アップ | N_c = 3 | 0 | 1.777 | 1.770 | 0.4% |
| ダウン | N_c = 3 | −N_c | 2.273 | 2.276 | 0.1% |

ここで R は対数階層の形を捉えるものであり——質量比を一様に伸縮しても（各 m_i/m_j を共通の冪に上げても）不変である——個別の質量ではない。表の精度列は予測値の実測中心値に対する偏差である。実測側の R には軽クォーク質量の不確かさ（PDG 2026: m_u = 2.16 ± 0.07 MeV 等）が約 ±0.15–0.25% の幅として伝播し、比較はさらに各質量のスキーム・スケール規約（軽クォークは 2 GeV の MS-bar、c・b は m(m)、t は直接測定質量）に依存する[^absquark]。

[^absquark]: 個別クォーク質量の大きさは、本論文では導出しない。Paper II はセクター内の比を導出したうえで、六つの絶対質量を導出済みの量だけで書く閉形式を与える——意味の固定は明示された物理的同定により、方式と定義点の変換は続きの計算として残る。同定の検討に用いた六つの実測質量との一致は、独立検証には数えない。

## 7.3. ニュートリノ質量と絶対スケール

§7.1–7.2 で荷電フェルミオン（レプトン、クォーク）の質量比を導いた。残るはニュートリノである。

**質量予測。** ニュートリノはカラー一重項であるため κ = 1 で V = −H に結合する——荷電レプトンと同じポテンシャルである。質量比 R は井戸の形状（IPR とビリアル比）のみに依存し、粒子種には依存しない。同じ井戸は同じ R を与える：

$$R_\nu = R_\mathrm{lepton} = 1.529$$

これが本節の、実験入力を含まない予測である。以下で確立するスペクトル比 (m₃/m₂)² = 169/5 と合わせると、*無次元*の質量射線 が振動データの入力なしに完全に定まる。

meV 表示の絶対質量には、無次元の内部量を人間の単位へ写す量がひとつ要る。本論文はそれを電子質量 m_e = 0.51099895069(16) MeV（CODATA 2022 [34]）に取る——素粒子の質量のうち最も精密に測られた量（相対 3×10⁻¹⁰）であり、荷電レプトンとニュートリノからなる連結した質量系の一員だからである。この一点で内部の質量単位が定まり、電弱スケール v はその単位で予測される量になる：v = 246.2360 GeV（Fermi 定数 G_F = 1.1663788(6)×10⁻⁵ GeV⁻² から定まる 246.2196 GeV に対して +6.7×10⁻⁵）^II^。ニュートリノ部門に第二の尺度は要らず、m_e 自体は独立予測に数えない。最も軽いニュートリノと電子の質量比は、指定された演算子語から導かれ、同じ単位で測った物理的な質量比として読まれる^II^：

$$\frac{m_1}{m_e} = x^3\,\frac{7}{6}\Bigl(1 + \frac{\varepsilon^2}{9}\Bigr) = 6.097 \times 10^{-10},\qquad x = \frac{9\alpha}{26\pi}$$

x は §5.3 の展開量であり、§8.1 では Cabibbo 角の色遮蔽としても現れる。ニュートリノ質量が荷電レプトンのそれを10桁下回ることは、この量が三乗で効くことの帰結である。荷電レプトンを表示した単位は、この比を通じてそのままニュートリノへ伝わる。振動データは、式・係数・分枝のいずれの選択にも用いない。正常順序を条件として次が得られる[^numass]：

| 量 | 予測 | 状態 |
|---|---|---|
| m₁ | 0.3116 meV | 未測定 |
| m₂ | 8.667 meV | 整合 |
| m₃ | 50.39 meV | 整合 |
| Σm_i | 59.37 meV | Planck 以下（<120）|

[^numass]: 表示桁は、絶対規格化に用いる荷電レプトン側の高次評価をどこで打ち切るかに依存する。その評価には、表示次数を超える補正について未固定の同定が残っており、表示桁はその条件を引き継ぐ^II^。質量射線 は内部で固定されているため、三つの質量はいずれも共通の単位に比例する。理論に自由パラメータはない。正常順序は本節では入力条件であり、その独立導出は定理として与えられる^II^（R_ν > 1 と (m₃/m₂)² = 169/5 > 1 の帰結）。これらは絶対スケール m_e を定めた後に現れる帰結であり、独立な予測としては数えない。

同じ単位の下では、二つの振動分裂はいずれも計算を終えた後に比較する量になる——Δm²₂₁ = 7.5016 × 10⁻⁵ eV²（実測 7.537 × 10⁻⁵ eV² に対して −0.47%）、Δm²₃₁ = 2.5387 × 10⁻³ eV²（実測 2.521 × 10⁻³ eV² に対して +0.70%）。ただし、この共通の単位を検査する自由度は一つであり、二つを独立な二件の検定と数えることはできない。両者の比は、次に述べる質量射線 を検査する量である。

旗ラプラシアンのスペクトルが 厳密に固定するのは

$$\Bigl(\frac{m_3}{m_2}\Bigr)^{\!2} = \frac{169}{5},\qquad \frac{m_3}{m_2} = \frac{|\mathrm{PG}|}{\sqrt{N+2}} = \frac{13}{\sqrt{5}} = 5.814$$

である。分子の 169 は、§5.3 のスペクトルだけから従う2つの初等的事実で決まる。第一に、非零固有値 4∓√3 は共役対をなし、その積は射影平面のサイズを厳密に再現する：

$$(4-\sqrt3)(4+\sqrt3) = 16 - 3 = 13 = |\mathrm{PG}(2,\mathbb F_3)|$$

したがって別個の規格化は入らない。第二に、この対の固有ベクトル v₁, v₂ を入れ替える対合を ς と書き、二重項 ψ = cos θ_H·v₁ + sin θ_H·v₂ を考える（係数角 θ_H は大気角 θ₂₃ とは別の量である）。交換不変性 ςψ = ±ψ は等重み |cos θ_H| = |sin θ_H| を強制し、コヒーレント振幅の大きさは符号の選択に依らず |13 sin 2θ_H| = 13 となる。この振幅の強度 13² = 169 への二乗は第二の同定ではなく、同定の下の定理として証明される^II^。

分母の 5 = N+2 = 3+2 は太陽チャンネル在庫の階数であり、その導出——在庫の網羅性を含む——は作用素跡の定理として与えられる^II^。質量二乗差比は、これと R_ν = R_lepton から t = m₁/m₂ を消去した完全な関係式

$$\frac{\Delta m^2_{31}}{\Delta m^2_{21}} = \frac{169/5 - t^2}{1 - t^2} = 33.842\ldots\quad(\text{表示 } 33.84)$$

で与えられる^II^。

非零の m₁ の下では 169/5 は質量二乗差比の厳密値ではない。上の完全な関係式は振動データの入力なしに 33.84 を与える。実測値の比は 2.521/0.07537 = 33.45 であり、理論値と実測値はこの 1.2% だけ異なる。振動データを絶対スケールの決定に用いていないため、この差はどこにも吸収されず、検定対象としてそのまま立つ。上表の質量は、丸め前の値において内部比 m₃/m₂ = 13/√5 = 5.814 を厳密に満たす（表示桁から再計算すると丸めの端数が残る）。

**質量公式の適用範囲。** §7.1 の質量公式が定めるのはセクター内の質量比であり、その全体の比例定数はセクターごとに異なる。最も軽いニュートリノと電子を結ぶ比だけは指定された演算子語から導かれ、これによりレプトンの質量系は絶対スケール m_e ひとつで閉じる^II^——セクター間の無次元比 m(ν₃)/m(τ) ~ 3×10⁻¹¹ もこれで定まる。クォークの絶対質量は Paper II の閉形式が与え（§7.2 の脚注）、方式と定義点の変換が続きの計算として残る。
