# 8. 混合角——CKM と PMNS

§7 でフェルミオンの質量比を導いた。本章では世代間の混合——クォークの CKM 行列とニュートリノの PMNS 行列——を導き、あわせてニュートリノの Dirac 性を導く。

## 8.1. CKM 混合

§7.1–7.2 で質量比が確定した。次に世代間の混合 [24] を導く。なぜ V_ub は小さく、Cabibbo 角 [19] はあの値なのか。標準模型はこれらを説明しない。V = −H では、ポテンシャルの対称性が前者に、第3世代の限界性が後者に対応する。

ポテンシャル V = −H は対称である：V(φ) = V(−φ)。これにより固有関数はパリティが確定する：ψ_0 偶、ψ_1 奇、ψ_2 偶。異なるモードの直接的重なりは Sturm-Liouville 直交性により ⟨ψ_0|ψ_2⟩ = 0。ψ_0 と ψ_2 はともに偶であるから、V-パリティ奇の混合演算子に対して ⟨ψ_0|M|ψ_2⟩ = 0——先導的な 0↔2 遷移が禁じられる：

$$V_{ub}\big|_\mathrm{tree} = 0$$

実測値 |V_{ub}| ≈ 0.004 は Wolfenstein 階層の高次から生じる（最初の非零項は下記の閉形式で与える）。

Cabibbo 角はスペクトル的限界性から従う。第3束縛状態 ψ₂ は限界的に束縛されている——その束縛エネルギー |E₂| = 0.010 は井戸の深さのわずか1.5%である。この限界性を測る量は、厳密な束縛状態数と半古典的作用カウントの差である：

$$\varepsilon = N - n_\mathrm{WKB} = 3 - 2.781 = 0.219$$

混合角は質量固有状態と弱固有状態の不一致を反映する。第3束縛状態が限界的（ε > 0）であることが混合の源であり、ε → 0 でこの源が除かれる形式極限では、3世代は保たれたまま各遷移式がゼロへ向かう（この形式極限が一つのユニタリ CKM 行列の族を定義しないことは §8.2 で述べる）。混合角を ε の級数として与える対応規則（遷移を運ぶ演算子と、その次数・分母）は、観測可能量ごとに一意性が証明されている^II^（§5.2 の一覧）。2次まで：

$$\sin\theta_C = \varepsilon(1 + \varepsilon/N^2) = 0.2245 \quad (\text{実測: } 0.2243,\; 0.10\%)$$

この値は無遮蔽の内部値である。色遮蔽を合成した値は sinθ_C·(1−x) = 0.22435（x = N²α/(2π|PG|) = 9α/(26π) は色遮蔽の展開量；導出は Paper II）。

Cabibbo 角から Wolfenstein 階層 [25] が従う：|V_{us}| ∼ ε、|V_{cb}| ∼ ε²、|V_{ub}| は少なくとも O(ε³) まで抑制され最初の非零項は 2ε⁴（実測値: 0.225, 0.041, 0.004）。NLO 補正は 1 ± ℓε/k の形をとる。分母 k と符号・係数 ℓ の割り当ては §5.2 の一覧のとおり（sinθ_C は 1+ε/9、sin²θ₁₃ は 1−2ε/3）。定理として証明される^II^完全な閉形式は

$$|V_{cb}| = \varepsilon^2\left(1-\frac{2\varepsilon}{3}\right) = 0.0410,\qquad |V_{ub}| = 2\varepsilon^4\left(1-\frac{2\varepsilon}{3}\right)\left(1-\frac{3\varepsilon}{26}\right) = 0.00384$$

である。

これらの指数と係数 2 の由来は離散的である。世代遷移を運ぶのは三世代の置換のうちパリティ奇のものに限られる（V-パリティの帰結）。隣接遷移 1↔2 と 2↔3 はそれぞれ互換 t₁₂ と t₂₃ が実現する。生成順序が定める旗 V₁ ⊂ V₂（第1世代の張る直線と、第1・2世代の張る平面）に対し、壁のコストを「動かす最浅の旗レベル」で数えると、t₁₂ は V₁ を動かすのでコスト 1、t₂₃ は V₁ を固定して V₂ だけを動かすのでコスト 2——これが |V_us| ∼ ε と |V_cb| ∼ ε² の指数である。

パリティが消すのは一段の直接 1↔3 要素であって、二段の合成経路 1→2→3 そのものを禁止するわけではない——奇の挿入を二回合成すると偶になり、二つの行列要素の積は零でない。両者を分けるのは生成型である：合成語は合成木が異なるため、同じ観測可能量の無視した項ではなく別の観測可能量である^II^。

1↔3 を直接運ぶ奇置換は、三世代を反転する最長置換 w₀ である。w₀ は三つの壁 t₁₂・t₂₃・t₁₃ を全て横断し、コストの総和は 1 + 2 + 1 = 4——最初の非零項が ε⁴ となる理由である。係数 2 は、w₀ の最短分解（ギャラリー）がちょうど二本あり、点-ライン双対がその二本を入れ替えることによる。壁あたり ε というコストの割り当てと、この数え上げは、いずれも対応規則の下の定理として証明されている^II^。

V(φ) = V(−φ) というパリティ対称性は直接の 0↔2 フレーバー遷移を抑制するが、QCD 真空角を単独では固定しない。パリティだけでは θ ∈ {0, π} が残る。

観測可能な strong-CP 角は

$$\bar\theta = \theta_\mathrm{QCD} + \arg\det M_q$$

この2項がともに消えることは、Paper II の強いCPマッチング定理が示す：A1–A3 を、作用・フェルミオン行列式・大ゲージ変換の実現まで保って適用すると、arg det(M_u M_d) = 0 と裸の θ_QCD = 0 が従い、マッチング点で θ̄(μ₀) = 0 となる。裸の θ_QCD を消す機構は、正の測度 ray を保つユニタリスカラーが 1 に限られること（測度線の自明性^II^）であって、本節の V-パリティ単独ではない。

ただし、これはマッチング点での言明であり、全スケールの厳密零ではない。弱 CKM ループと閾値を含む赤外の θ̄_IR について、Paper II は宣言次数——弱 O(G_F²)・カイラル O(p²)・large-N_c カイラル摂動論の枠組み——における条件付き上界 |θ̄_IR| < 6.0×10⁻¹⁷ を与える。全次数の評価は続きの計算である。したがって、PQ 型大域 U(1) の不在から排除される PQ 型アクシオンを超えて、アクシオン様粒子一般の不存在を主張することはできない。

一方、CKM セクターでは CP 破れが観測されている（J = 3.16 × 10⁻⁵ [22]）。これは裸の θ_QCD = 0 と矛盾しない：CKM 位相は ε の高次で生じる：

$$J = \frac{\pi\varepsilon^5}{N_\mathrm{flags}} = \frac{\pi\varepsilon^5}{52} = 3.06\times10^{-5}$$

（N_flags = 52 は旗の総数、§4.1；対応規則の下の定理^II^）。マッチング点の条件は厳密にゼロのままである。

strong-CP の帰属をまとめる：

| 量 | 予測 | 実測値 |
|---|---|---|
| 裸の θ_QCD | **V-パリティの帰結ではない**（強いCPマッチング定理^II^によるマッチング点の値 θ̄(μ₀)=0） | —（上限 \|θ̄_IR\| ≲ 10⁻¹⁰ は赤外量に課され、直接比較不可） |
| CKM CP 破れ | J = πε⁵/N_flags（対応規則の下の定理^II^） | 3.06 × 10⁻⁵（実測 3.16 × 10⁻⁵） |

## 8.2. PMNS 混合

§8.1 で CKM 混合角は ε = 0.219 から得られた——小さな値（sinθ_C ≈ 0.22）である。ところがニュートリノの PMNS 混合角は大きい（sin²θ₁₂ ≈ 1/3）。同じ V = −H からなぜ大小2種類の混合が生じるのか。

答えは色荷の有無にある。クォークは色を持ち V = −3H の深い井戸内にあるため、モードの重なりが小さい摂動的領域に入る——この局在の描像はクォーク混合の小ささと整合し、その展開径数は世代セクターの限界性 ε（§3.2）である（式そのものの根拠は Paper II の生成旗次数と遮蔽語にある）。

一方ニュートリノは色中性であり、PG(2,3) 上のゲージ方向の幾何的配分が混合角に対応する値を直接与える。太陽混合角は1つの完全な電弱ライン（N+1 = 4 点）が PG の13方向に占める分率：

$$\sin²θ_{12} = 4/13 = 0.3077 \quad (\text{実測: } 0.3088,\; 0.4\%)$$

大気混合角の LO は、純弱の N 方向と基準点を通る別の直線（N+1 点）との非交和が PG の13方向に占める分率 7/13 である。これに PG スケールの NLO 補正（k = |PG| = 13）が加わると：

$$\sin²θ_{23} = (7/13)(1 + ε/13) = 0.5475 \quad (\text{第二オクタント})$$

LO の分率 7/13 は 1/2 を上回るため、第二オクタントを予測する。NuFIT 6.1 [28] の大域ベストフィットは第一オクタント（sin²θ₂₃ = 0.470）に移ったが、オクタントは未確定であり、予測値 0.5475 は 3σ 許容域（0.432–0.587）の内側にある。NuFIT 6.1 の χ² プロファイルの第二オクタント側の局所極小は 0.550 にあり、予測値のそれからの偏差は 0.45% である[^nufitgrid]。反応器角は sin²θ_{13} = 1/(N·|PG|) = 1/39 に NLO 補正（k = N = 3）を加えて：

[^nufitgrid]: 局所極小は公開グリッドを Δm²₃₁ と δ_CP について射影して得られる。大域最小に対し Δχ² ≈ 1.03、sin²θ₂₃ のグリッド刻みは 0.005。特に断らない限り、本論文で引用する NuFIT 6.1 の値は、上記の Δm² 入力と整合する SK-atm なし・正常順序のデータセットである。

$$\sin²θ_{13} = (1/39)(1 - 2ε/3) = 0.0219 \quad (\text{実測: } 0.02249,\; 2.6\%)$$

和則：7/13 = 3/13 + 4/13（LO で sin²θ₂₃ = sin²θ_W + sin²θ₁₂）は、13 を分母とする有限計数の恒等式である。ただしこれは形式的な和であり、純弱の3点は完全電弱ラインの4点に含まれる（両集合は交わり、合併は4点）ため点集合の分割ではない——大気角の7方向の幾何的由来は上記の非交和である。NLO 補正はこの和則を破り、その形は Paper II が与える。

**PMNSとCKMの位相。** 大気ホロノミー比 q₂₃ = (7/13)(1+ε/13) = sin²θ₂₃ は、定理として証明される^II^形でPMNS位相も直接固定する：

$$\delta_{\rm PMNS} = 2\pi q_{23} = 197.1^\circ$$

CKM位相はεだけの単一閉形式には還元されない：§8.1 の3つの混合量——遮蔽後の sinθ_C、|V_cb|、|V_ub|——とCP奇不変量 J = πε⁵/N_flags を1つのユニタリCKM行列へ埋め込み、sinδ = J/(c₁₂s₁₂c₂₃s₂₃c₁₃²s₁₃)を、cos δ > 0（符号はA1の初期経路持ち上げで固定）とあわせて解くことで定まる。これも定理として証明され^II^、

$$\delta_{\rm CKM} = 62.595^\circ,\qquad \beta = 23.972^\circ,\qquad \gamma = 62.560^\circ$$

を与える（実測値: δ_CKM = 66.1°、γ = 66.4° [22]）。β と γ は同じユニタリ行列から剛的に従うため、δ と γ の実測差は同じ一つの位相差であり、独立な二検定には数えない^II^。三つの角と J は独立に導かれるので |sinδ| ≤ 1 は非自明な制約であり、これを満たすのは ε ≳ 0.204——導出値 0.2192 はその内側にある。各遷移式は形式的には ε → 0 でゼロへ向かうが、四式が一つのユニタリ CKM 行列へ同時に収まるのはこの範囲であり、共通の ε → 0 CKM 族を定義しない。

## 8.3. ニュートリノの性質

ニュートリノは Dirac か Majorana か——未解決の実験的問題である。本枠組みは明確な予測を与える。数演算子代数の位相共変性（a → e^{iθ}a）に、導出済みの粒子在庫・一つのヒッグス・四つの非零 Dirac 辺・アノマリーフリーな整数指標格子・生成構造の自然性を合わせると、残る大域位相方向は B−L に一意に定まる^II^。マヨラナ双線形 aa + a†a†（Δ(B−L) = 2）はこの B−L の下で非零荷重を持つため、不変部分に残らない。V-パリティは ν と ν^c（レプトン数 L = ±1）を Dirac フェルミオンに対にする（演算子レベルの証明：Paper II の Dirac 選択定理）。従ってニュートリノなし二重ベータ崩壊は厳密にゼロである：

$$0\nu\beta\beta = 0$$

以上で、フェルミオンの質量比（§7）、混合角、ニュートリノの性質が V = −H と PG(2, F₃) の構造から得られた（絶対質量は正常順序を前提とし、絶対スケールは m_e の一点である）。標準模型がこれらを独立な自由パラメータとして扱うのに対し、本枠組みでは全てが1つの方程式 V = −H の代数的展開の異なる側面である。
