# 近藤研究所

近藤研究所は東京にある私設研究所で、理論物理・情報理論・暗号・分散コンピューティングを研究しています。中心となるのは存在からの物理学（Existence Theory）——3つの公理から、自由パラメータなしに標準模型のパラメータを導出する枠組みです。

本リポジトリは研究所の公開ドキュメントを収めています。研究内容そのものはウェブサイト <https://www.kondo-lab.com/> から読むのが早く、ここに置くのはその背後にある参照資料です。プレーンテキストのまま読め、記述対象と一緒にバージョン管理される形にしてあります。
